# 鲁智深醉闹五台山 - 使用指南

> 上美影风格项目，平涂定版风格（与早期"水墨+赛璐珞"工艺的差异见下方对照表）。
> 题材：水浒英雄传奇·醉闹喜剧 | 彩蛋：续作"倒拔垂杨柳"在 skill 的 references/上美影原始提示词.txt 中有现成实测提示词可直接改造。

## 项目概况

| 项 | 内容 |
|----|------|
| 题材 | 英雄传奇·醉闹喜剧（水浒式） |
| 风格 | 上美影手绘动画（水墨线条+纯平涂主线，双端实测定版） |
| 色盘 | 青瓷绿、朱砂红、鎏金、墨黑 + 藤黄（黄瓦/袈裟/酒液） |
| 集数 | 5 集 × 15 秒，9:16 竖屏 |
| 情绪弧线 | 醉归山门 → 怒打金刚 → 大闹禅堂 → 长老叹悟 → 拜别下山 |

## 与旧版的关键差异

| 维度 | 旧版（水墨+赛璐珞） | 本版（上美影平涂） |
|------|---------------------|---------------------|
| 风格块 | Chinese ink wash + anime cel-shading | 平涂强化版 + 咆哮体硬约束 |
| 光影 | dramatic lighting / 金色光束 | 色块对比（平涂纪律，无体积光） |
| 比例 | 未定义 | 鲁智深六头身夸饰、长老五头身、小僧四头身 |
| 叙事 | 纯画面 | 加说书人旁白体制 |
| 色彩 | 黑白水墨基调 | 五色矿物颜料色盘（红墙黄瓦青山） |
| 声音 | 含配乐描述 | 只生成音效（唢呐类留后期） |

## 制作步骤

### 第一步：生成资产

1. 打开 `鲁智深醉闹五台山_素材清单.md`，逐条复制资产提示词
2. 提示词默认中文，即梦 / Seedream / 豆包直接使用；如用 Midjourney / GPT-Image 等英文模型，换用素材清单中的英文对照版风格块
3. 建议顺序：C01 鲁智深标准像（迭代到稳定）→ C01 四视图 → C02 砸金刚海报 → C03/C04 → S01-S04 → P01-P03
4. 出图后核对：**纯2D平涂（无阴影/无渐变/无3D体积）+ 大面积留白** + 比例正确

### 第二步：逐集生成视频

1. 打开 `鲁智深醉闹五台山_E01_分镜.md`，按素材上传清单上传资产图
2. 复制 Seedance Prompt 整段粘贴生成（15秒、9:16）
3. E02 起把上一集成片作为 @视频1 上传，Prompt 以 `将@视频1延长15秒` 开头
4. E02/E03 的"慢速夸张"打斗段若崩坏：抽帧 → 用风格块出图改图 → 图生视频重跑

### 第三步：后期剪辑

1. 五集按序拼接；打斗段落卡**戏曲锣鼓点**（砸金刚、踹香炉的动作落点配"仓才"）
2. 旁白配音：说书人声线，文案取剧本"说书人（画外音）"
3. 角色配音建议：鲁智深声如洪钟带酒气含混，小僧尖细发颤，长老苍老缓慢
4. 配乐（后期另配）：E01-E03 唢呐+锣鼓的豪迈诙谐，E04 静室古琴独奏，E05 钟声+笛箫悠远
5. 字幕：【字幕：xxx】条目在剪辑软件手动添加

## 本剧专项技巧

| 技巧 | 用法 | 本剧落点 |
|------|------|----------|
| 慢速夸张 | 砸金刚、踹香炉放慢半拍，力道感+滑稽感兼得 | E02 9-12秒、E03 9-12秒 |
| 大小体量反差 | 六头身巨汉 vs 四头身小僧的同框惊恐 | E02 对峙段 |
| 动静对比 | E03 鸡飞狗跳紧接 E04 静室檀香，一闹一静出喜剧呼吸感 | 集与集之间 |
| 装饰性可视化 | 酒气画成波浪纹、香烟画成细线，用图案代替写实 | E01/E03/E04 |
| 声音留白 | E04 只留画外喧闹与一声叹息，静默即笑点 | E04 全集 |

## 风格自检（每集出片后核对）

- [ ] 首行风格行与色盘逐字一致（五集互查）
- [ ] **纯2D平涂：无阴影、无渐变、无3D体积感、无柔光光晕**
- [ ] **大面积留白（海报/场景图强制）**
- [ ] 造型为概括手绘（非写实、非日漫），墨黑轮廓线可见
- [ ] 色彩为大块装饰性平涂，符合五色盘（青瓷绿/朱砂红/鎏金/墨黑/藤黄）
- [ ] 画面有水墨线条感与胶片颗粒感
- [ ] 打斗动作慢而夸张，无高速崩坏
- [ ] 尾帧描述中的色盘与风格词在画面中可对应
