# 分镜优化与声音设计指南

## 一、声音设计（先看这一节）

### 1.1 原生对白优先

**Seedance 2.0 能直接生成人物说话的视频，语音与口型都是原生出的。台词写进提示词，成片就有人说话；不写，人物全程闭嘴。这不是后期配音的活儿。**

三条声音轨道，各归各的写法：

| 轨道 | 内容 | 写在哪 | 标注 |
|---|---|---|---|
| 对白轨 | 人物当面说的话 | 【声音】段 `对白：` 逐条 | `同期声`（匹配口型） |
| 旁白轨 | 说书人旁白、不在画面里的人物 | 同一段 | `画外音` |
| 音效轨 | 环境音、动作音 | 【声音】段末尾 `音效：` | 不标 |

配乐**不写进提示词**（会和人对白抢声道），后期按需叠加。

### 1.2 标准写法

```
【声音】人物开口说话，生成同期对白语音并匹配口型；只保留对白与环境音效，不要配乐，不要生成任何字幕。
对白：
0-4秒 旁白（男声，沉缓说书腔，画外音）：「八十万禁军教头，一纸休书，发配沧州。」
4-8秒 陆谦（压低嗓音，赔笑，同期声）：「林教头的事，小可已经打点妥了。」
8-12秒 无对白
12-15秒 林冲（沙哑，一字一顿，同期声）：「你……也配提我娘子？」
音效：银锭磕在漆盘的闷响、烛花爆响、衣料摩擦声、门轴吱呀
```

四要素缺一不可：**开头总述"人物开口说话"** / **时间码** / **说话人+语气+声音属性** / **引号内的逐字台词**。

### 1.3 台词容量

中文语速约 4-5 字/秒，15 秒里要留音效和留白：

- 全集合计 **25-35 字**（硬上限 45），单拍 ≤12 字，单句 ≤15 字
- 超量就拆到相邻时间拍，或改剧本砍词（**先砍剧本，不许只砍提示词**）
- 每集至少 1 条人物同期对白，每集说话角色不超过 2 人

### 1.4 画面描述要同步写"开口"

台词只写在【声音】段不够，正文该拍要写"他开口说话""脱口道""低声笑道"。只给台词不给开口动作，模型可能闭着嘴说话。

### 1.5 常见失败与处置

| 现象 | 原因 | 处置 |
|---|---|---|
| 全程没人说话，只有环境音 | 【声音】段没写台词，或写了"只生成音效" | 按 1.2 重写 |
| 有声音但嘴不动 | 正文没写开口动作 | 该拍补"开口说话" |
| 赶词、吞字、语速飞快 | 台词超量 | 砍剧本台词或拆拍 |
| 多个角色声音串味 | 一集塞了 3 人以上对白 | 每集控制在 2 人以内说话 |
| 旁白变成角色口型 | 画外音没标"画外音" | 补声音属性 |

### 1.6 配乐与音效

- **配乐**：不进提示词。后期按需叠（民乐笛/古筝/琵琶 + 戏曲锣鼓点，武戏卡锣鼓点，文戏用笛箫）。可用 Suno、网易天音、剪映音乐库等，注意商用授权。
- **音效三层**：环境音（建空间）→ 动作音（增真实）→ 特殊音效（强冲击）。只写明确的环境/动作音效。
- **音效来源**：即梦/可灵/剪映 AI 音效生成，或爱给网、剪映音效库素材叠加。

### 1.7 兜底配音（不是默认流程）

只有出现"模型吞字 / 多角色串音 / 必须改词 / 用户指定音色"时才用：MiniMax、DubbingX、ElevenLabs、IndexTTS2、GPT-SoVITS、即梦克隆音色。

**不要因为用了这些工具，就反过来把台词从提示词里删掉。**

提取角色音色：剪映里选中不超过 5 秒的说话片段（I 设起点、O 设终点）→ 导出音频 → 后续生成时作为音频参考上传。

## 二、分镜优化

### 2.1 分镜图的三个用途

| 痛点 | 解法 |
|---|---|
| 复杂极限镜头抽卡率高 | 先生成分镜图，再跑图生视频 |
| 镜头崩坏要补救 | 抽帧 → 改图 → 重新图生视频 |
| 需要精美静态空镜/情绪定格 | 分镜图直接出，或转成短镜头 |

### 2.2 出图提示词公式（上美影版）

```
【风格指南 §2.1 风格块】+【景别与视角】+【主体描述】+【环境场景】+【色块对比与色调（点色名）】+【画质修饰】
```

不写侧光、伦勃朗光、柔光、光晕、景深，明暗一律用"色块并置"表达（朱砂红对青瓷绿）。

### 2.3 多资产融合

```
请将图1中的[角色]无缝置入图2的[场景]中，[动作]。[色块与色调]。严格保持参考图的手绘动画画风与色盘。
```

### 2.4 图生图常用指令

| 目的 | 指令 |
|---|---|
| 换视角/景别 | `基于此图，生成[视角/景别]，姿势与动作保持不变。` |
| 四宫格场景参考 | `生成 2*2 四宫格场景多视角参考图：左上俯拍、右上正向、左下左侧、右下右侧，四格同一空间、同一光照、同一色调。` |
| 九宫格角色多视角 | `生成不同视角与景别，姿势动作不变，3*3 九宫格，左上角标数字序号。` |
| 局部修改 | `将[主体]的[部位/物品][修改内容]，其余保持不变。` |
| 角色站位图 | 复杂室内场景先出人物位置关系图，确保空间关系清晰。 |

### 2.5 视频抽帧修补

1. 抽崩坏前最后一帧
2. 用图生图改这一帧（`将男人手握的物件去掉，手指向前方，其余不变。`）
3. 以此图作首帧，重新生成后半段
4. 剪辑软件拼接

### 2.6 字幕消除

模型出的字幕常糊字、位置不可控，所以提示词里禁止生成字幕。若已带字幕：剪映 AI 消除（智能选取最长帧 → 涂抹 → 消除），或 LibTV 智能擦除。

## 三、素材衔接

| 方法 | 写法 | 注意 |
|---|---|---|
| 抽帧接力 | `将@图片X作为首帧` | 取上一段尾帧作下一段首帧，最稳 |
| 延长视频 | `将@视频1延长15秒` | 抽卡率较高、音色还原一般，但集间最连贯 |

镜头组接原则：光影、站位差异不大；角色一致；情绪连贯。

---

## 四、常见问题

| 问题 | 解法 |
|---|---|
| 多角色同框生成失败 | 单角色分别生成短片段，过审后合并 |
| 视频质量下降 | 用抽帧接力替代延长功能 |
| 角色一致性差 | 提供标准像 + 四视图参考，风格词逐字一致 |
| 场景被画进白底道具 | 视频参考只挂角色图与场景图，道具靠文字描述 |
