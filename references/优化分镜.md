# Seedance 2.0 提示词优化指南

## 万能公式

**主体 + 动作 + 场景 + 色块 + 镜头语言 + 风格 + 画质 + 约束**

"约束"这一层是防崩关键，不能少。

### 上美影版示例

- 【主体】头戴毡笠、身披破旧蓑衣的教头，5-7 头身，墨黑粗轮廓线，朱砂红直裰压暗纹
- 【动作】缓慢推开庙门，肩膀先动，袍角随后摆起（动作写慢，有起止）
- 【场景】雪夜山神庙，青瓷绿远山，月白背景留白，装饰性雪纹填充
- 【色块】朱砂红对月白，两色平涂并置，不要过渡
- 【镜头语言】中景推近，最后三秒切近景
- 【风格】上美影手绘动画风格块（`上美影风格指南.md` §2.1）
- 【画质】8K，纯2D平涂
- 【约束】纯 2D 平涂，无阴影、无渐变、无 3D 体积感，画面无文字

## 关键词速查

### 动作
缓慢、轻顿、连贯、不僵硬；写"怎么开始、落到哪里"（抬起手把令箭往自己这边一拨），不写静态姿势。

### 镜头
缓慢推近、拉远、左右摇、横移、跟随、环绕半圈、升降、固定机位。

### 景别
远景、全景、中景、近景、特写、大特写。**相邻两拍必须换。**

### 色调
只写色盘里的色名（朱砂红、青瓷绿、鎏金、墨黑、赭石、月白…），用"色块对比"表达明暗，不写侧光、逆光、柔光、光晕、景深。

### 约束防崩
纯2D平涂、无阴影、无渐变、无3D体积、无文字水印、人物结构完整不变形、动作不僵硬。

## 注意事项

- **动作写慢**：越慢越稳，避免"高速""剧烈扭动"。
- **别写主观词**：漂亮、帅气、很酷、震撼——模型无法理解，等于没写。
- **别写抽象效果**：色块炸开、同心纹荡开，要改成位置+颜色+形状+占比。
- **一拍一个动作**：超两个动作模型只做一个，剩下时间定格。
