## 一、什么是"上美影感"

上美影 = 上海美术电影制片厂。它在中国动画发展中形成了高辨识度的美术语言：大量吸收中国传统艺术（水墨、工笔、剪纸、木偶、年画、壁画、戏曲、民间美术），转化为动画里的角色造型、色彩和画面语言。

**"上美影感"不是一种固定画风**，不同作品差异很大。本 skill 主线提取的是其中**偏传统手绘动画**的部分，五条视觉特征及提示词抓手：

| 特征 | 含义 | 提示词抓手（英/中） |
|------|------|---------------------|
| 高度概括的人物造型 | 删繁就简、夸张重点，非写实比例 | bold and simplified contours / 概括简练的轮廓 |
| 手工感的线条 | 不完美、有抖动感的笔触轮廓 | imperfect brushstroke outlines / 手工感笔触轮廓 |
| 大面积装饰性色彩 | 平涂色块分割画面，矿物颜料质感 | traditional mineral pigment colors / 矿物颜料配色、装饰性色块 |
| 大胆的平面构图 | 弱化纵深透视，强调图层叠与留白 | bold flat composition / 平面化构图 |
| 传统绘画质感 | 水墨+水粉肌理、胶片颗粒 | ink wash and gouache texture, animated film grain / 水墨水粉肌理、胶片颗粒 |

**风格坐标（内部参照系；片名可作中文平台的可选锚定词 A/B，见 §2.3，Midjourney 仍避免）：**

| 经典作品 | 视觉路线 | 与本 skill 关系 |
|----------|----------|-----------------|
| 大闹天宫 / 天书奇谭 / 哪吒闹海 | 工笔重彩 + 装饰线 | **默认主线最接近的坐标** |
| 小蝌蚪找妈妈 / 牧笛 | 水墨淡彩 | 子风格模块（§九） |
| 九色鹿 | 敦煌壁画重彩 | 子风格模块（§九） |
| 葫芦兄弟 / 猪八戒吃西瓜 | 剪纸 | 子风格模块（§九） |

## 二、风格块（三级 + 硬约束层）

> **实测教训（2026-08 回填）**：旧版风格块中 `soft hand-painted edge diffusion / slightly blurred painted edges / delicate gouache bleeding texture / soft color halo` 等柔边晕染短语，会把多数生图模型推向**渐变、阴影、3D 体积感**渲染，导致"不像上美影"。修订版默认块已删除这些短语，并强制附加 §2.4 硬约束层（咆哮体警告）。旧版全文归档于 §2.6，仅供 Midjourney + `--profile 5zmmma6` 环境使用。
>
> **✅ 2026-08-25 双端复测确认：平涂强化版风格块（§2.1/§2.2）+ 咆哮体硬约束（§2.4）生图端实测达标（纯2D平涂、无阴影渐变3D体积），定版为图片默认。**任何人不得以"增加质感"为由往 §2.1/§2.2 图片默认块加回柔边/晕染/色晕类短语；图片端需要肌理变化走子风格模块（§九）。
> **✅ 同日第三轮复测确认：v3 视频行（恢复质感词族+精准反3D）实测上美影手绘感达标，定版。三轮结论：图片块（§2.1/§2.2+咆哮体）与视频行（§2.3 v3）配方分开维护，勿互相套用；视频端禁用绝对化"无阴影无渐变"。**

### 2.1 完整版·平涂强化（中文，默认，生图主用）

**中文为本 skill 的默认提示词语言**（用户与主流出图平台即梦/Seedream/豆包均为中文语境）。`[本剧色盘中文]` 替换为 §三 声明的剧组色盘。**结尾两条强命令不可删**：

```
上美影风格（上海美术电影制片厂复古手绘动画），中国传统手绘二维动画，传统矿物颜料纯平涂色块，大胆概括的轮廓线，带手工感的不完美笔触轮廓，装饰性平面背景纹样，模拟动画胶片颗粒感，浓郁的中国幻想美学，主色：[本剧色盘中文]。必须纯2D平涂！绝对不要阴影、不要渐变、不要3D体积感！必须大面积留白！
```

### 2.2 英文对照版·平涂强化（可选，Midjourney 等英文模型用）

仅在 Midjourney / GPT-Image 等英文模型上使用；语义与 2.1 完全一致：

```
vintage Shanghai Animation Film Studio aesthetic, traditional Chinese hand-drawn 2D animation, flat color fields in traditional mineral pigment colors, bold and simplified contours, imperfect hand-drawn brushstroke outlines, decorative flat background patterns, simulated animated film grain, rich Chinese fantasy aesthetics, [本剧色盘英文], ultra-detailed, 8K. CRITICAL: 2D FLAT COLORS ONLY. ABSOLUTELY NO SHADING, NO GRADIENTS, NO 3D VOLUME. Vast empty negative space is MANDATORY.
```

### 2.3 精简版（Seedance 视频提示词首行专用）

**v3 配方（2026-08-25 第三轮修订，✅ 同日实测达标，定版）**。修订原因：v2 在平涂修正时把"手绘质感词族"与"反3D"捆绑删除——图片端有效（§2.1/§2.2 维持 v2 不动），但视频端失去手绘味（实测：鲁智深 5 段 + 罗刹 1 段上美影感不足，画面像干净的普通二维动画/CG）。v3 恢复质感词族，否定词改为精准反3D：

```
上海美术电影制片厂经典手绘动画风格，手绘墨线轮廓，水粉平涂上色、保留颜料笔触与手工感，矿物颜料色（[本剧主色简写]），概括造型，胶片颗粒感，不要3D渲染、不要写实感、不要体积光
```

**v3 设计要点：**
1. 品牌用**全称**"上海美术电影制片厂"——比缩写"上美影"锚定更强（罗刹图片端已验证全称可用）；
2. "手绘墨线轮廓"替代"水墨线条"——上美影是墨线勾勒，不是水墨晕染，旧词会把画面往水墨画带；
3. 平涂靠**正向词**"水粉平涂上色"锚定；否定词只打击真敌（3D渲染/写实感/体积光），不再用"无阴影无渐变"绝对化禁令——它会连手绘肌理一起杀掉；
4. 视频端"大面积留白"按构图需要选用，不强制每镜留白。

**子风格视频行变体**（替换上式中的媒介质感部分"手绘墨线轮廓，水粉平涂上色、保留颜料笔触与手工感"，其余逐字保留）：

| 子风格 | 媒介质感替换词 |
|--------|----------------|
| 主线（默认） | 手绘墨线轮廓，水粉平涂上色、保留颜料笔触与手工感 |
| 敦煌重彩 | 手绘墨线轮廓，陈年壁画矿物重彩，斑驳壁画肌理与轻微颜料过渡 |
| 水墨淡彩 | 写意墨线轮廓，墨色浓淡晕染与淡彩过渡 |
| 剪纸风 | 分层剪纸剪影，对称装饰纹样，实色平涂刻线边缘 |
| 石蓝淡墨绘本 | 淡雅磨砂平涂，强线条感，小面积怪色点缀 |

**片名锚定（可选强化，A/B 用）**：中文平台可把品牌短语换成片名锚定试更强锚定，如"大闹天宫式经典手绘动画""九色鹿式敦煌壁画动画""葫芦兄弟式剪纸动画"；若触发平台审核则回退全称。Midjourney 环境仍避免片名。

### 2.4 硬约束层（咆哮体警告，所有生图提示词必附）

强命令对生图模型的约束力显著强于普通描述，作为**每条资产/海报/分镜图提示词的固定结尾**：

**中文版（默认）：**
```
必须纯2D平涂！绝对不要阴影、不要渐变、不要3D体积感！必须大面积留白！
```

**英文版（Midjourney 等英文模型用）：**
```
CRITICAL: 2D FLAT COLORS ONLY. ABSOLUTELY NO SHADING, NO GRADIENTS, NO 3D VOLUME. Vast empty negative space is MANDATORY.
```

使用规则：
1. 2.1 / 2.2 风格块已内嵌此命令，无需重复添加；自撰提示词时必须手动附上；
2. 角色标准像（白背景）天然满足留白要求，仍保留"纯平涂"命令；
3. 命令逐字使用，不要改写标点或措辞（实测口径）。

### 2.5 负面提示词库

支持负面提示词/排除参数的平台，直接复制叠加：

**中文（默认，即梦/Seedream 提示词末尾追加）：**


|-----------|--------|

| 冲突、爆发 | 朱砂红、墨黑 |

| 荒凉、悲壮 | 赭石、墨黑 |

### 3.5 怪色点缀技法（来自"石蓝淡墨绘本"实测资料）

在基准盘之外配 1 个"意料之外、情理之中"的点缀色（如汤红、巧粉、金棕），**只用于小面积**——服饰滚边、器物、印章、一朵花、一只蝴蝶。画面立刻出彩且不破坏统一性；上美影经典（天书奇谭式）的配色智慧正是大胆的怪色配对。点缀色计入剧组色盘声明的扩展色（仍遵守"最多加 2 个"总量控制，点缀色优先占额）。

## 四、造型设计规范

上美影造型与写实短剧审美**直接相反**，以下规则替代旧版"二八比例"体系：

| 维度 | 规则（上美影） |
|------|----------------|
| 身材比例 | 概括化头身比：成人主角 5-7 头身；孩童/神童 3-4 头身；异兽/神怪自由夸饰 |
| 轮廓线 | **必写**：粗细（通常较粗）、颜色（通常墨黑）、手工抖动感 |
| 服装 | **必带纹样**：云纹、回纹、水纹、火焰纹、戏曲靠旗、年画图案等装饰元素；色彩为整块平涂 |
| 表情 | 资产标准像中性；情节海报要求"戏曲亮相感"的夸张表情 |
| 反派 | **允许并鼓励装饰性丑化**（尖嘴猴腮、三角眼等图案化丑），但保持装饰美感，不做恶心化处理 |
| 儿童/老人 | 解禁：神话/民间题材常见（哪吒式孩童、土地公式老者），按对应头身比设计 |
| 辨识度 | 每个角色一个**专属主色 + 专属纹样**（写进人物小传的视觉形象栏） |

### 异兽/神怪设计规则

1. 形体可自由夸饰，但轮廓必须概括可读（远看剪影即能识别）；
2. 必须有**神性标记**：鎏金部位、发光器官、独有纹样之一；
3. 特征尽量贴合典籍原文（如夔牛"苍身无角一足"、相柳"九首人面"）；
4. 一律使用 §五-B 异兽场景型模板出图。

## 六、构图原则（写画面描述时贯彻）

1. **平面化**：弱化透视纵深，强调前景/中景/背景的图层叠关系；
2. **大色块**：画面由 2-3 块装饰性色块分割（如：主体朱砂红 + 远山青瓷绿 + 天空月白）；
3. **留白**：借水墨留白造意境，角色在画面中的占比可克制（人物海报除外）；
4. **装饰填充**：背景用云纹、水纹、山纹等图案化元素填充，不用写实碎细节；
5. **轮廓优先**：先保证剪影可读，再加内部细节；
6. **平涂纪律**：所有明暗关系用**深浅色块并置**表达（阴影就是一块更深的平涂色），不用渐变过渡；布光描述改写为"色块对比"（如"朱砂红袍对青瓷绿墙"），不写"侧光/伦勃朗光/柔光/光晕"等会诱发体积渲染的词。

## 七、Seedance 视频端风格注入

1. **首行固定**：每集提示词第一行 = §2.3 v3 风格行 + 本剧色盘简写 + 时长/画幅/氛围。除"氛围"词外，风格行**逐集逐字相同**——防风格漂移的硬机制。子风格剧按 §2.3 变体表替换媒介质感词。
2. **正文风格强化（v3 新增）**：风格不能只押首行——长提示词尾重头轻，首行会被稀释。每个时间段落（0-3秒/3-6秒/…）的描述中**至少自然嵌入一个风格词**：手绘墨线、颜料笔触、平涂色块、剪纸剪影、壁画肌理、老动画胶片感等，写进主体或背景描述里。
3. **参考图画风锁定（v3 新增）**：【参考】行末尾必须加画风锁定语："严格保持参考图片的手绘动画画风与色盘"（子风格剧替换为对应画风名，如"敦煌壁画画风""剪纸动画画风"）。Seedance 能从参考图锚定画风，但需要显式要求。
4. **尾帧描述带风格**：每集尾帧描述必须包含色盘与至少一个风格词，保证下一集接力不丢风格。
5. **资产引用**：`@图片X` 引用 C/S/P 资产图；角色一致性靠 C01 标准像 + 四视图，场景一致性靠三机位图。
6. **动作写"慢"**：手绘动画质感的动作宁慢勿快，避免高速剧烈运动导致崩坏（与 优化分镜.md 通用规则一致）。
7. **运镜对冲与 E01 浓度**：全篇电影运镜术语（推/摇/跟）会把模型往实拍质感带，第 2 条的正文强化词同时起对冲作用；E01 的风格浓度要最高——后续集靠"延长"继承 E01 画风，E01 定调即全剧定调。

## 八、叙事与声音适配

### 8.1 说书人旁白体制

上美影经典大量使用说书人式第三人称旁白。短剧剧本中把"画外音旁白（vo）"提升为**推荐手段**：开场定调、过场压缩、结尾点题都用旁白，正对 15 秒×N 集的高信息密度需求。旁白文案要求：文言白话相间、短句、有韵律感。

### 8.2 题材—模板映射

| 题材 | 说明 | 首选模板 |
|------|------|----------|
| 神话志怪（山海经式） | 异兽、神祇、创世 | B 异兽场景型 + A 人物型 |
| 英雄传奇（水浒式） | 武人、快意恩仇 | A 情节海报版 |
| 民间故事/寓言 | 机智人物、动物寓言 | A + C |
| 文人诗意（古文/诗词改编） | 意境流、弱叙事 | C 场景空镜为主 + 旁白 |

### 8.3 声音设计

- **配乐**：民乐（笛、古筝、琵琶）+ 戏曲锣鼓点；武戏动作卡锣鼓点，文戏用笛箫；
- **音效**：保留"只生成音效，不生成音乐不生成字幕"的 Seedance 约束；
- **配音**：旁白用说书人声线（沉、稳、有说书腔）；角色对白可向戏曲韵白靠拢；
- 工具推荐沿用 `分镜优化与声音设计.md` 第二章。

## 十、常见翻车与修复

> 实测记录：2026-08-25，平涂强化版风格块 + 咆哮体硬约束经实际验证**有效达标**——生图端（纯2D平涂、大面积留白）与 Seedance 视频端（§2.3 精简版首行）双双通过。
> **第三轮（同日）**：扩大测试（鲁智深 5 段主线 + 罗刹 1 段敦煌）发现视频端"防3D有效但上美影手绘感不足"——根因：v2 精简版删光质感词族 + 敦煌子风格视频首行自相矛盾。部署 v3（§2.3 + §七第2/3条）后**实测达标，定版**。以下条目为历史问题与备选修复手段。

| 症状 | 原因 | 修复 |
|------|------|------|
| **视频平涂对了但没有手绘味（像干净CG/普通二维动画）** | v2 视频行删光了质感词族（水粉肌理/笔触/手工感） | 换 §2.3 v3 配方：恢复质感词，否定词只留反3D三连（不要3D渲染/写实感/体积光） |
| **子风格视频无敦煌/水墨感** | 视频首行"斑驳壁画肌理"+"无渐变"自相矛盾（罗刹实测） | 用 §2.3 变体表的媒介质感替换词，删掉"纯2D平涂无阴影无渐变" |
| **画面出现阴影/渐变/3D体积感（生图）** | 柔边晕染类短语（旧版块）或模型默认渲染倾向 | 提示词末尾附 §2.4 咆哮体硬约束；清除 soft glow/晕染/色晕/柔光 等词；叠加 §2.5 负面词 |
| **画面塞得太满、没有留白** | 构图元素过多 | 主体精简至 1-2 个；附 "Vast empty negative space is MANDATORY"；背景改图案化留白 |
| 出图变写实真人 | 混入写实词/旧比例词 | 检查是否残留 photorealistic、皮肤纹理、二八比例；补 "2D animation, flat stylized shapes" |
| 风格日漫化 | 旧前缀/动漫词干扰 | 停用 anime cel-shading/赛璐珞/anime/manga；用 traditional Chinese hand-drawn 2D animation |
| 色彩寡淡 | 未带色盘 | 按 §3.3 声明色盘并逐字引用 |
| 轮廓太干净像矢量图 | 缺手工感词 | 确保 imperfect brushstroke outlines / hand-painted edge diffusion 在场 |
| 跨集人物漂移 | 风格行/色盘不一致 | 逐字校验 + C01 四视图资产 + 尾帧接力三重机制 |
| 视频端风格丢失 | 提示词过长 | 首行只用 2.3 精简版，动作描述精简，总长控制 |
| 异兽画成普通野兽 | 缺神性标记 | 按 §四异兽规则补鎏金部位/发光器官/独有纹样 |
